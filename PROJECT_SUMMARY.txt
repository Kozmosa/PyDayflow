🚀 部署和使用
─────────────────────────────────────────────────────────────────────────

快速启动:
  1. 双击 start.bat (Windows) 或运行 ./start.sh (Linux/Mac)
  2. 复制 .env.example 到 .env
  3. 设置 GEMINI_API_KEY
  4. 访问 http://localhost:5000

系统要求:
  • Python 3.8+
  • 4GB+ RAM
  • 500MB+ 磁盘空间
  • Windows 10/11 (推荐)

性能指标:
  • CPU: <5%
  • 内存: ~200MB
  • 存储: ~100MB/天
  • 网络: 仅AI分析时使用
