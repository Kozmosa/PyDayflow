# PyDayflow Web界面功能说明

## 界面组件

### 1. 页头 (Header)
- 显示应用标题 "🎯 PyDayflow"
- 副标题：自动记录屏幕活动并生成时间线
- 渐变背景（蓝色到紫色）

### 2. 录制控制面板
**按钮:**
- "开始录制" (绿色按钮) - 开始屏幕录制
- "停止录制" (红色按钮) - 停止录制
- 录制状态指示器

### 3. 操作面板
**按钮:**
- "立即分析" (蓝色) - 手动触发AI分析
- "清理旧数据" (橙色) - 删除超过保留期的录制
- "刷新时间线" (紫色) - 更新时间线显示

### 4. 系统状态面板
显示:
- 录制状态（正在录制/未录制）
- 采集帧率
- 存储空间使用
- 录制文件数量
- 分析状态

### 5. 时间线显示区域
- 日期选择器 - 选择查看特定日期
- 时间线卡片列表，每个卡片显示:
  - 时间范围（开始-结束）
  - 活动标题
  - 详细摘要
  - 分类标签（工作/个人/分心）

## 颜色方案
- 工作活动: 蓝色边框
- 个人活动: 绿色边框
- 分心活动: 橙色边框

## 响应式设计
- 支持桌面和移动设备
- 自适应布局
- 触摸友好的界面

## 交互功能
- 自动每30秒刷新状态
- 即时反馈通知
- 平滑的动画效果
- 悬停效果增强用户体验
